# MySchoolApp

A simple student registration form built with React.

## Features

- Student registration form with fields:
  - Student Name
  - Class
  - Mobile Number
  - Stream (Science/Commerce/Arts)
  - Subject
  - Guardian Name
- Logs form data to browser console on save
- Shows success message after saving

## Prerequisites

- Node.js (v14 or higher)
- npm

## How to Run

1. Navigate to the MySchoolApp directory:
   ```bash
   cd MySchoolApp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Usage

1. Fill in the student details in the form
2. Click "Save"
3. Open browser Developer Tools (F12) → Console tab to see the logged data
4. A success message will appear briefly after saving
